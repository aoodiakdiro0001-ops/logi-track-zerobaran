------------------------------------------------------------
  الموارد المجانية المستخدمة في البناء
------------------------------------------------------------

• GitHub Actions    - محرك التشغيل المجدول (Cron)
• Python + FastAPI  - محرك المعالجة اللوجستية
• Gemini / Groq     - العقل الذكي (Free Tiers)
• Supabase          - قاعدة البيانات (PostgreSQL Free)
• Telegram Bot API  - قناة الاستقبال والتنبيهات
• Streamlit         - لوحة تحكم الويب

------------------------------------------------------------
  البنية المعمارية - 4 طبقات
------------------------------------------------------------

1. طبقة التسجيل والمتابعة (Ingestion & Polling)
2. العقل الذكي وصياغة الإشعارات (AI Notification Core)
3. طبقة الأرشيف وقاعدة البيانات (Persistence Layer)
4. طبقة التوصيل والتنبيه الفوري (Delivery & Control)

------------------------------------------------------------
  طريقة التشغيل السريع
------------------------------------------------------------

1. ثبّت Python 3.11+
2. pip install -r requirements.txt
3. انسخ .env.example إلى .env واملأ المفاتيح
4. نفّذ scripts/setup_database.sql على Supabase
5. python main.py status     (للتحقق من الاتصالات)
6. python main.py api        (لتشغيل API)
7. python main.py bot        (لتشغيل بوت تليجرام)
8. python main.py dashboard  (لتشغيل لوحة التحكم)

لمزيد من التفاصيل، راجع README.md و INSTALL.md.
