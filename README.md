# 🚚 Logi-Track ZeroBaran

> **المنظومة الذاتية الذكية لتتبع الشحنات، إدارة مسارات التوصيل، وإشعارات العملاء**

نظام ذكي متكامل ومستقل لتتبع حالة الشحنات والطلبات، رصد مسارات التوصيل، وتحديث العملاء آلياً عبر رسائل فورية حول موقع طرداتهم — يقوم بربط بيانات شركات الشحن أو المتجر، تتبع خط سير الشحنة لحظة بلحظة، تقدير وقت الوصول، وإرسال تنبيهات ذكية ومخصصة للعملاء عند كل خطوة — **دون دفع دولار واحد لأي منصة تتبع مدفوعة، وبموارد مجانية بالكامل**.

## 🌟 لماذا Logi-Track ZeroBaran؟

### 💰 توفير مال فلكي
اشتراكات أدوات التتبع اللوجستي وإشعارات العملاء تكلف الشركات مبالغ طائلة سنوياً؛ هذا النظام يؤدي نفس الغرض باحترافية عسكرية **بتكلفة صفر**.

### 📉 القضاء على استفسارات الدعم (Zero Support Tickets)
عندما يعرف العملاء مكان شحنتهم بدقة ومتى ستصلهم آلياً، تنخفض اتصالات الشكاوى والاستفسارات بشكل ملحوظ.

### 🔒 السيادة والخصوصية التامة
بيانات عملائك، مسارات الشحن، وعناوين التوصيل لا تُشارك مع أي شركات تتبع خارجية بل تُحفظ في بيئة سرية خاصة بك.

## 🛠️ الموارد المجانية البحتة المستخدمة في البناء

| المكون | الخدمة / التقنية | الدور |
|---|---|---|
| محرك التشغيل والمتابعة المجدولة | **GitHub Actions** | خادم مجاني لتنفيذ فحص حالات الشحنات دورياً (كل ساعة) |
| محرك المعالجة والمنطق اللوجستي | **Python + FastAPI + HTTPX** | سحب بيانات الشحن، معالجة التغيرات، حساب أوقات التوصيل |
| محرك الذكاء الاصطناعي | **Google Gemini / Groq API** (Free Tiers) | صياغة رسائل الإشعارات الودية، تحليل أسباب التأخير |
| قاعدة البيانات | **Supabase (PostgreSQL Free Tier)** | تخزين أرقام التتبع، الحالة، بيانات العملاء، سجل التحركات |
| قناة الاستقبال والتنبيهات | **Telegram Bot API + Streamlit** | واجهة تسجيل الشحنات وإرسال الإشعارات الفورية |

### الطبقات الأربع:

1. **طبقة تسجيل ومتابعة الشحنات (Ingestion & Polling)** — سكريبت بايثون يعمل داخل GitHub Actions ليفحص دورياً حالة الشحنات.
2. **العقل الذكي وصياغة الإشعارات (AI Notification Core)** — استغلال Gemini API لترجمة الحالة التقنية إلى رسالة إنسانية راقية.
3. **طبقة الأرشيف وقاعدة البيانات (Persistence)** — Supabase Postgres يحفظ تفاصيل كل شحنة ومسارها التاريخي.
4. **طبقة التوصيل والتنبيه الفوري (Delivery & Control)** — Telegram Bot + Streamlit لإرسال التحديثات الفورية.

## ⚙️ طريقة العمل خطوة بخطوة

1. **الحدث:** يقوم متجرك أو عملك بشحن طلب لعميل، فتُدخل رقم التتبع واسم العميل إلى النظام عبر بوت تليجرام أو لوحة التحكم.
2. **المتابعة التلقائية:** يستيقظ خادم GitHub Actions دورياً ليتفحص أحدث مستجدات خط سير الشحنة.
3. **التحديث والصياغة:** إذا تغيرت الحالة، يطلب النظام من الذكاء الاصطناعي صياغة رسالة إشعار احترافية ومناسبة للعميل.
4. **النتيجة الفورية:** يتلقى العميل تحديثاً فورياً عن شحنته، ويصلك تقرير لوجستي على هاتفك — كل ذلك يدور بسلاسة تامة ودون دفع سنت واحد!

## 🚀 التشغيل السريع

### المتطلبات
- Python 3.11+
- حساب Supabase (مجاني)
- مفتاح Google Gemini API أو Groq API (مجاني)
- بوت تليجرام (مجاني)
- حساب GitHub (مجاني - لـ GitHub Actions)

### التثبيت

```bash
# 1. استنساخ المشروع
git clone <repository-url>
cd Logi-Track-ZeroBaran

# 2. إنشاء بيئة افتراضية
python -m venv venv
source venv/bin/activate  # Linux/Mac
# أو: venv\Scripts\activate  # Windows

# 3. تثبيت التبعيات
pip install -r requirements.txt

# 4. إعداد متغيرات البيئة
cp .env.example .env
# عدّل ملف .env وأضف المفاتيح الحقيقية

# 5. تنفيذ مخطط قاعدة البيانات على Supabase
# انسخ محتوى scripts/setup_database.sql إلى SQL Editor في Supabase

# 6. تشغيل النظام
python main.py status      # فحص الحالة
python main.py api         # تشغيل خادم API
python main.py bot         # تشغيل بوت تليجرام
python main.py dashboard   # تشغيل لوحة التحكم
python main.py poll        # تشغيل دورة فحص واحدة
```

للتفاصيل الكاملة، راجع [INSTALL.md](INSTALL.md).

## 🌐 REST API Endpoints

| الطريقة | المسار | الوصف |
|---|---|---|
| GET | `/` | معلومات عامة عن النظام |
| GET | `/health` | فحص صحة النظام |
| GET | `/api/customers` | قائمة العملاء |
| POST | `/api/customers` | إضافة عميل جديد |
| GET | `/api/customers/{phone}` | بحث عن عميل |
| GET | `/api/shipments` | قائمة الشحنات |
| POST | `/api/shipments` | تسجيل شحنة جديدة |
| GET | `/api/shipments/{tracking_number}` | تفاصيل شحنة |
| POST | `/api/shipments/track` | تتبع فوري عبر شركة الشحن |
| PUT | `/api/shipments/{id}/status` | تحديث حالة شحنة |
| GET | `/api/shipments/{id}/events` | سجل أحداث شحنة |
| GET | `/api/notifications` | سجل الإشعارات |
| POST | `/api/notifications/compose` | توليد وإرسال إشعار |
| GET | `/api/stats` | إحصائيات لوحة المعلومات |
| POST | `/api/admin/poll-now` | تشغيل فحص فوري |

توثيق Swagger الكامل: `http://localhost:8000/docs`
